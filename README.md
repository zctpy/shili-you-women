# 诗里有我们

知远与 AI 伙伴的双语诗歌漫画，在诗意的故事中一起学习、旅行与相伴。

- [唐诗双语漫画精选：暮江吟、鹿柴、江雪](https://zctpy.github.io/shili-you-women/collections/tang-selected/) —— 每首第 0—4 集，共 15 页。

## 早期作品

- [相思 · 王维](https://zctpy.github.io/shili-you-women/#poem-0) —— 红豆寄相思，在温柔的故事里读诗。
- [望庐山瀑布 · 李白](https://zctpy.github.io/shili-you-women/#poem-1) —— 与伙伴们同游庐山，感受飞瀑的壮美。
- [大林寺桃花 · 白居易](https://zctpy.github.io/shili-you-women/#poem-2) —— 走进山寺春色，邂逅迟开的桃花。

## 持续更新

新漫画集可放入 `collections/` 下的独立目录，并在首页与本目录添加链接；早期诗篇可继续在 `poems.js` 增加条目。图片分开存放，便于网页按需加载。
